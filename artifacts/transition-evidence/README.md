# Transition evidence

The PNG sequence in this directory is generated by `e2e/transition-visual.spec.ts`.
Filenames are ordered by scene and transition phase so compaction, convergence, exit,
handoff, and entrance can be reviewed frame by frame. The same test samples every
animation frame to assert that `coreReady` is within 4 px of the stage center and that
the orb fully crosses the right edge before the next scene or round expands.
